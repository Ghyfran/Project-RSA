# PROJECT RSA - SISTEM KEAMANAN

# Judul : Aplikasi Desktop Sederhana untuk Simulasi Enkripsi dan Dekripsi Pesan Menggunakan Algoritma RSA

# Bahasa Pemrograman:
Python

# Tools:
1. Visual Studio Code
2. Tkinter

# Cara Menjalankan:
1. Buka visual Studio Code
2. Jalankan file main.py
3. Klik tombol Generate Key
4. Masukkan plaintext
5. Klik Enkripsi
6. Klik Dekripsi

# Fitur:
1. Generate Key RSA
2. Enkripsi Pesan
3. Dekripsi Pesan
4. Reset Sistem

Catatan:
Aplikasi ini merupakan simulasi pembelajaran RSA dan bukan sistem keamanan nyata.
